# Weekend Movie Watchlist

A simple React mini-app for adding and removing movies from a watchlist.

## Features
- Six movies stored in an array
- Movie cards rendered with `map()` and a unique `key`
- Add/remove toggle button for each movie
- Live watchlist count
- Clear watchlist button

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm start`.
